## Before publishing

1. Replace the initials placeholder in `index.html` with the approved profile photo (`assets/profile.jpg`).
2. Confirm the names of the two Loyola teaching-assistant courses.
3. Create the public GitHub repository named `ceiroa.github.io`, push the files to its default branch, and enable GitHub Pages from that branch.
